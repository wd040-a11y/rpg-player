📱 데스크톱 없이 아이폰(iOS) 단독으로 이용하는 방법 & 저장 구조

1. 데스크톱 PC를 켜두지 않고 아이폰 단독으로 쓰는 가장 확실한 방법

• 1단계 (최초 1회 패키지 생성): PC에서 게임을 불러온 뒤 우측 상단 [📦 완전체 Game.zip 내보내기]를 누르면, 복호화된 표준 PNG 이미지·초상화·동영상과 대본이 모두 들어있는 단일 _Standalone.zip 파일이 생성됩니다.

• 2단계 (아이폰 단독 실행):
① 생성된 _Standalone.zip 파일을 아이폰(iCloud Drive / 파일 앱 / 카카오톡 나에게 보내기 등)으로 옮깁니다.
② 이 플레이어를 GitHub Pages(동봉된 .github/workflows/deploy-pages.yml로 자동 배포되는 내 웹 주소)로 접속하거나, 아이폰 무료 앱 Documents by Readdle에서 rpg_story_player_pro.html을 열고 [+ ZIP / iOS 파일 열기]로 ZIP을 불러옵니다.
③ 상단의 [📲 기기에 영구저장] 버튼을 한 번 누르면 아이폰 내부 데이터베이스(IndexedDB)에 게임이 통째로 저장되어, 이후에는 PC가 꺼져 있든 인터넷이 없든 아이폰 단독으로 즉시 열람할 수 있습니다!

2. 원본 게임 파일 삭제 가능 여부

• [📦 완전체 Game.zip 내보내기]를 실행해 만든 ZIP 파일 안에는 실제 복호화된 이미지와 동영상 바이너리가 모두 포함됩니다. 따라서 내보낸 ZIP 파일만 보관하시면 수 기가바이트짜리 원본 게임 폴더는 완전히 삭제하셔도 됩니다.
